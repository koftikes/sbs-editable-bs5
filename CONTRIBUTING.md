# Contributing

## Setup

Clone the repository and install dependencies:

```bash
git clone https://github.com/koftikes/sbs-editable-bs5.git
cd sbs-editable-bs5
npm install
```

## Development server

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Tests

Run tests:

```bash
npm test
```

Run tests in watch mode:

```bash
npm run test:watch
```

## Linting

Run the linter:

```bash
npm run lint
```

Automatically fix lint issues:

```bash
npm run lint:fix
```

For the release process, see [`PUBLISHING.md`](PUBLISHING.md).
