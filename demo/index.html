Demo @sbsweb/editable-bs5

Click any underlined value to edit it. No backend is running - everything except the "Networking" section works purely locally.

Keyboard: Tab to a value, Enter/Space to open it, Esc to cancel and return focus to the trigger.

Settings

Mode:

Mode and Disable all apply live to every example on this page. Refresh just reloads the page (same as F5) - undoes edits, closes open editors, and resets rows left in an error or destroyed state.

Number

Setting Example Code
Custom HTML5 attributes + render()   
new Editable(el, {
  type: 'number',
  title: 'Enter number',
  value: '30000.00',
  render: (value) => {
    const [i, d] = parseFloat(value).toFixed(2).split('.');
    return `${i.replace(/\B(?=(\d{3})+(?!\d))/g, ' ')}.${d}`;
  },
  attributes: {
    placeholder: 'Enter number',
    min: 0.1, max: 5000000, step: 0.1,
    required: true,
  },
});

Autocomplete

Type 2+ characters to filter.

  • Arrow Down/Up highlights a suggestion without leaving the input (keep typing to refine)
  • Enter picks the highlighted one
  • Esc closes just the suggestion list first, a second Esc closes the editor

const USERS = [
    { value: '42', text: 'Alice Johnson' },
    { value: '17', text: 'Bob Smith' },
    { value: '9', text: 'Bobby Fischer' },
];

Setting Example Code
Strict (default) - try typing something that matches nothing, then Save   
new Editable(el, {
  type: 'autocomplete',
  title: 'Assign to user',
  value: '42',
  source: USERS,
});
Strict - type the exact label by hand, don't click it, then Save (still works)   
new Editable(el, {
  type: 'autocomplete',
  title: 'Type "Bob Smith" by hand, then Save',
  value: '42',
  source: USERS,
});
allowCustomValue: true - anything typed is accepted   
new Editable(el, {
  type: 'autocomplete',
  title: 'City',
  value: 'Berlin',
  allowCustomValue: true,
  source: ['Berlin', 'Bern', 'Belgrade', 'Bern (Switzerland)'],
});
source as a Promise (1.5s delay) - same loading overlay as select   
new Editable(el, {
  type: 'autocomplete',
  title: 'Loads after 1.5s',
  value: '17',
  source: () => new Promise((resolve) =>
    setTimeout(() => resolve(USERS), 1500)),
});
threshold / maxItems tuned explicitly   
new Editable(el, {
  type: 'autocomplete',
  value: '9',
  source: USERS,
  threshold: 1,
  maxItems: 3,
});

Custom type

Setting Example Code
Registered via Editable.registerType / Editable.BaseType   
class RatingType extends Editable.BaseType {
  create() {
    const select = this.createElement('select');
    [1, 2, 3, 4, 5].forEach((n) => {
      const opt = document.createElement('option');
      opt.value = String(n);
      opt.textContent = '★'.repeat(n);
      select.append(opt);
    });
    return this.createContainer(select);
  }
}
Editable.registerType('rating', RatingType);

new Editable(el, { type: 'rating', title: 'Pick a rating', value: '3' });

Networking

All requests below actually fire - open DevTools → Network, or watch the Console below. Everything fails with no backend running.

Setting Example Code
URL - plain string Submitting Me 
<span data-type="text" data-title="Send to /api/demo" data-url="/api/demo">Submitting Me</span>
URL as a function - resolved per-submit from ctx.element and the new value try submitting me 
new Editable(el, {
  url: (ctx, newValue) =>
    `/api/records/${ctx.element.dataset.recordId}?value=${encodeURIComponent(newValue)}`,
});
requestBuilder - full control over the request (JSON body instead of FormData) try submitting me 
new Editable(el, {
  url: '/api/rb-demo',
  requestBuilder: (ctx, newValue, url) => ({
    url,
    init: {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ value: newValue }),
    },
  }),
});
